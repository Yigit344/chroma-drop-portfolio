## Featured Project: Chroma Drop

**Genre:** Hyper-Casual Arcade  
**Engine:** Unity  
**Platform:** Android  
**Status:** Playable Prototype

Chroma Drop is a fast-paced color-matching arcade game. Players switch the active color to catch matching falling blocks while avoiding mismatches. The game features increasing difficulty, combo rewards, unlockable cosmetics, and a progression system.

### Features
- One-touch arcade gameplay
- Progressive difficulty
- Combo scoring and visual feedback
- Unlockable cosmetics and daily rewards
- Mobile portrait orientation
- Modular structure prepared for advertising SDK integration
